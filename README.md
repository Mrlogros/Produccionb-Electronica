## 📖 Sobre el Proyecto

Este repositorio contiene los archivos fuente y el desarrollo paso a paso de nuestra placa de circuito impreso. El objetivo es documentar el flujo de trabajo profesional desde la concepción del diagrama lógico hasta el ruteo físico y las modificaciones finales.

Toda la documentación detallada, capturas de pantalla del proceso, listas de materiales (BOM) y justificaciones de diseño se encuentran organizadas en nuestra página web oficial:

👉 **[Acceder a la Documentación Interactiva del Proyecto](https://mrlogros.github.io/Produccionb-Electronica/)**

## 📂 Estructura del Repositorio

* `docs/`: Contiene los archivos Markdown (`.md`) y las imágenes (`img/`) que construyen la página web de documentación.
* `mkdocs.yml`: Archivo de configuración estructural y estético del sitio web.
* *(Aquí se irán agregando los archivos fuente del proyecto de KiCad, como los `.kicad_pro`, `.kicad_sch`, etc.)*
